 🏎️ F1 Telemetry Dashboard

A modern and interactive Formula 1 data visualisation website designed to help F1 fans explore drivers, circuits, lap times, race telemetry, pit stops, and performance comparisons.

The project combines our interest in Formula 1 with web development and Python-based data analysis. It provides an easy-to-use dashboard where users can explore Formula 1 information in a visually engaging way.

---

 🚀 Features

- 🏁 Interactive Formula 1 dashboard
- 👨‍✈️ Driver information and profiles
- 🗺️ Formula 1 circuit and track visualisation
- 📊 Lap-time analysis
- ⚡ Driver performance comparison
- 🔄 Race telemetry visualisation
- 🛞 Pit-stop information
- 📱 Responsive and user-friendly design
- 🎨 Modern Formula 1-inspired interface

---
